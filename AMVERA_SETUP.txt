1. Создайте проект на https://cloud.amvera.ru/projects
2. Выберите тариф «Начальный Плюс» (490 ₽/мес)
3. Загрузите файлы проекта (Git push или через интерфейс)

4. В настройках приложения → «Переменные окружения» добавьте:

   OPENAI_API_KEY = ваш_ключ_openai
   FLASK_SECRET_KEY = любая_длинная_случайная_строка
   PYTHONUNBUFFERED = 1

5. Дождитесь статуса «Успешно развернуто»
6. Откройте URL: https://<имя-проекта>.amvera.io

Git (если используете):
   git remote add amvera https://git.amvera.ru/<логин>/<имя-проекта>
   git push amvera master
